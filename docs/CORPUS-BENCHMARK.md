# 语料基准验证报告（CORPUS BENCHMARK）

> 版本：v1.22.2 · 更新：2026-08-22 · 语料：arXiv 开放获取论文源码 **70 篇 × 9 学科**

## 目的与原则

启发式检查器的阈值若只在合成样本上调试，遇到真实学术文本必然系统性失准。本基准用
**真实已公开的 arXiv 论文源码**做分布级校准，遵循两条对抗性原则：

- **防过拟合**：只依据跨语料的分布统计做阈值调整，禁止针对单篇论文打补丁；
- **防欠拟合**：每次调整后必须重跑全量植入缺陷回归测试（129+ 用例），检测力不得衰减。

## 流程

1. `benchmarks/fetch_corpus.py` 拉取 e-print 源码（断点续传）；
2. `benchmarks/run_benchmark.py` 解包 → `\input` 一层合并 → `audit_paper(source_format="latex")`
   → JSONL 明细 + 分布汇总。

## 校准前后的关键变化

首轮真实语料跑分暴露系统性失准：三篇知名已发表论文得 **0/0/17 分**，一篇经济学工作
论文被误判 AI 痕迹"高"档。据此做了六类分布级修正（详见 CHANGELOG v1.21.0）：

1. TTR → **MATTR** 移动窗口词汇丰富度（消除长度偏差：长文 TTR 必然塌缩）；
2. 纯中文文本不再因无英文词被扣英文丰富度缺分；
3. LaTeX 引用核对改为 **\cite/\bibitem 键级比对**；`\input` 子文件与外部 .bbl 场景诚实降级；
4. 重复句分级（2 次=info）；每文档 duplicate 警告上限 5 条；
5. 样本口径检测要求样本语义词上下文（数学 N=… 豁免）；
6. 术语检查限正文、CS/ML 缩写表扩充、转换占位符与标题词豁免、thebibliography 剥离。

## 校准后结果（70 篇）

| 指标 | 数值（70 篇） |
|------|------|
| 分数中位 / 均值 | **82 / 77.1** |
| 分布（20 分桶） | {80+: 46, 60-79: 19, 40-59: 2, <40: 3} |
| AI 痕迹档位 | **70/70 全部"低"**（人类论文零误报） |
| ERROR 合计 | 27（集中于少数粗糙预印本的真实缺陷） |

分学科判读：数学/物理/神经科学类最规范（中位 82-88）；econ.GN 均值被两篇明显未打磨的
工作论文拉低至 50（中位仍 72），恰体现工具对真实质量差异的区分能力。

判读：经典高质量论文（如 Attention Is All You Need）得分 **90**；含大量样板重复的长
工作论文合理落在 41——分数具备区分度而非一刀切。

## 已知局限

- 语料为预印本而非定稿，部分低分来自真实的未打磨状态；
- 物理学部分投稿为 PDF-only，无法纳入 LaTeX 管线（PDF 解析是未来方向）;
- **语料全部为 STEM/定量范式**：人文阐释性文体（文史哲/法学教义）未纳入校准——check_ai_signature 对该类文体请用 `style="humanities"` 模式（剥离分布项，只保留词汇证据），详见 skills/paper-writing/references/discipline-matrix.md；该模式本身未经文科语料定量校准，档位仍仅供参考；
- **仅有人类论文负样本**：70/70 低分证明"人类论文零误报"，但未建立 AI 代写正样本对照（检出率/召回率未测）——分数定位是"待复核密度提示"，不是 AI 代写检测器；
- 启发式结论一律是"提示"而非"判决"，最终判断需人工复核。
