# literature-search：文献检索与调研

## 目标

在论文生产流程的"搜索环节"产出**可复现、可审计、引用零幻觉**的文献清单，为 Introduction / Related Work / 综述正文提供证据基础。本技能吸收业界成熟实践（nature-academic-search 的多源检索与他引审计、K-Dense literature-review 的综述流程与引用验证），整合为可直接执行的检索协议。

## 何时使用

- 论文选题期：验证主题是否已做滥、寻找 research gap；
- 写作前：为背景、现状、争议、缺口备料；
- 综述写作：系统性搜集 + 筛选 + 综合；
- 引文核验：确认某条文献真实存在、卷期页码正确、确为他人真实引用。

## 检索协议

### 1. 建检索式（先于检索）

- 拆主题为 **PICO 式核心要素**（研究对象 / 干预或方法 / 对照 / 结果），每要素给 2-3 个同义词。
- **优先用 paper-tools 的 `lit_search` 工具真实搜库**（调 Semantic Scholar API，按主题检索返回标题/作者/年份/被引/DOI），再结合客户端自身检索能力对关键文献做多库交叉验证。
- 主渠道 + 辅渠道：按主题选主渠道（计算机/ML → arXiv + Semantic Scholar + DBLP；生物医学 → PubMed + Web of Science；综合 → Google Scholar + Scopus + CNKI），**至少 2 个库**，单库检索是综述最常见的遗漏源。
- **渠道可达性诚实声明**：paper-tools 可直连的检索入口只有 `lit_search`（Semantic Scholar）与 `journal_search_openalex`（OpenAlex）；WoS/Scopus/CNKI 等需要账号凭据的库，由用户提供检索结果或明确标注"该库未检索（无访问权限）"——严禁声称已检索实际不可达的数据库。
- 主题词 + 自由词组合，布尔逻辑（OR 收同义词、AND 组合要素），记录完整检索式与检索时间以保证可复现。
- 时间窗口：默认近 3-5 年，综述类向前放宽至 10 年以覆盖里程碑工作。

### 2. 引文追踪

- **前向追踪**：找到领域核心论文后，检索引用它的后续工作（把握领域演进与最新进展）。
- **后向追踪**：沿核心论文参考文献回溯经典源头。
- 以 3-5 篇领域"锚点论文"为起点做双向追踪，比盲目全库扫更高效。

### 3. 筛选（PRISMA 式）

- 记录：检索命中数 → 去重后数 → 标题/摘要筛除数 → 全文筛除数 → 最终纳入数，**每一步给出去除理由**。
- 纳入/排除标准在筛选前写明（语言、年份、研究类型、证据等级），防止筛选时被结果牵着走。
- 同一主题被多篇综述覆盖时，优先纳入近年高被引综述与原始研究，避免只读二手转述。

### 4. 引文验证（防幻觉核心）

对每条要写进论文的文献执行验证。公开评测显示主流大模型伪造或错引参考文献的比例可达两成到五成（随模型、领域与年份波动），因此**未经程序化验证的引用一律不得落笔**：

- **存在性验证**：优先调用 paper-tools 的 `citation_verify` 工具（真实调 Crossref API）——按 DOI 精确核验，或按标题检索；返回的标题/作者/期刊/卷期页码/年份须与所引完全一致。API 不可达时再用客户端检索能力人工比对（标题、作者、年份、venue 至少四项精确匹配）。
- **字段级交叉验证**：DOI 可解析且卷期页码与 Crossref 一致；作者、年份与标题自洽；警惕同名作者不同人、同一标题多版本（会议版 vs 期刊版、预印本 vs 正式版）混淆。
- **无法验证即降级**：确认为占位条目，标记"待用户提供原始出处"，严禁编造 DOI 补齐。
- 每条最终文献记录至少包含：作者-年份-标题-来源-DOI/链接-核心观点-与本主题的关系。

### 5. 他引审计

- 用"被谁引用"判断文献影响力时，**区分真实他引与自引/引用圈**：一篇被自己团队反复引用的论文不等于被领域广泛认可。
- 核验被引数时注明计数来源与时间（不同库被引数口径差异很大），不把二手转述当一手事实。
- "关键争议"素材必须回到原始争论双方论文原文，不引用综述的二手转述充当立场。

## 综述写作（K-Dense 式流程）

1. **定框架**：明确综述类型（叙述性 / 系统性 / meta-analysis），系统性综述须声明检索协议（含数据库、检索式、时间窗口）。
2. **组织素材**：按"主题聚类 → 时间演进 → 争议焦点"三维组织文献，而非简单按年份罗列。
3. **综合而非罗列**：每段以结论句开头，用多篇文献支撑一个观点（"多研究一致表明…"），区分"一致证据 / 矛盾证据 / 证据空白"三类。
4. **可视化**：综述建议配 1-2 张图（研究趋势、方法分类、证据图谱），帮助读者建立结构认知。
5. **引用核验收尾**：提交前用 `verify_references(markdown=全文)` 对全部引文重跑批量验证（A/B/C 统计，C 级必须处理），保证"文献表每一条被正文引用、正文每一条引用在表中"——双向对应可用 `check_intext_citations` 机检。

## 与 ScholarSeed 其他技能的关系

- 本技能产出《文献清单》供 `paper-writing` 阶段 2 使用；检索式与验证记录随清单交付。
- 深度单篇阅读 / 证据卡片交给 `paper-card` 技能。
- 引文格式排版与 DOI 三重核对由 `paper-writing` 阶段 6（`citation-guide.md`）负责，本技能负责"文献是否真实存在且字段正确"的存在性核验，两环节互补。
- 详细检索渠道与策略见 `references/research-sources.md`；综述筛选与验证清单见 `references/literature-review.md`；他引审计细节见 `references/citation-audit.md`。

## 铁律

- **严禁编造文献、作者、年份、DOI、被引数**；无法验证的一律标记占位。
- 不把"检索到了"当作"验证过了"；存在性核验是落笔前提。
- 不因文献缺失就放宽纳入标准编造综述结论；证据空白要如实声明。
