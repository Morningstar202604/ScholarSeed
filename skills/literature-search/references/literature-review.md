# literature-review：综述筛选与综合流程

## PRISMA 式筛选（每一步留痕）

| 步骤 | 记录项 |
|---|---|
| 检索命中 | 各库命中数合计 |
| 去重 | 剔除跨库重复，记录去重后总数 |
| 标题/摘要筛选 | 按纳入/排除标准剔除，记录剔除理由（不相关 / 语言 / 年份 / 证据类型） |
| 全文筛选 | 读取全文后剔除，记录剔除理由（方法缺陷 / 数据不可得 / 与综述问题不符） |
| 最终纳入 | 纳入总数 + 纳入清单 |

纳入/排除标准必须在筛选**之前**书面写明：语言、时间范围、研究类型、证据等级要求。

## 综述结构组织

1. **主题聚类**：把纳入文献按子主题分组，每组内再按时间演进。
2. **争议焦点**：识别领域内 2-3 个真实争议，回到对立双方原始论文，不引用二手转述充当立场。
3. **证据分级**：区分"多研究一致支持 / 结果矛盾 / 证据空白"，综述的价值在如实呈现证据结构而非隐藏矛盾。

## 写作综合原则

- 段首句即结论句，段内以"（作者1, 年份；作者2, 年份）"形式并列引用支撑同一观点。
- 避免"年份流水账"（逐篇罗列"某某做了X，某某做了Y"），改为按观点聚类。
- 每篇纳入文献至少一句话说明其位置（开山 / 改进 / 争议 / 空白），保证"纳入即有用"。

## 综述常见坑

- 单库检索 → 命中不全（必须多库）；
- 引用未验证 → 错引、幽灵引用（必须跑验证）；
- 综述当文献列表 → 只有罗列没有综合（必须观点聚类）；
- 二手转述当一手（必须回原文）。
