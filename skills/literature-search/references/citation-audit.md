# citation-audit：引文验证与他引审计

## 存在性验证（落笔前提）

公开评测中 AI 生成参考文献的幻觉比例约为两成到五成（论文不存在 / 作者错 / 年份错 / DOI 伪造；随模型与领域波动），因此：

1. 每条待引用文献优先调用 paper-tools 的 `citation_verify` 工具（真实调 Crossref API）：有 DOI 按 DOI 精确核验，无 DOI 按标题检索，工具返回的元数据与所引逐项比对；
2. 核验项：标题、作者、年份、venue、DOI 五项，至少四项精确匹配；`citation_verify` 返回 `verified: false`（含 HTTP 404、网络不可达）时降级为人工核验或标记 `[待核实]`；
3. 无法核验的 → 标记 `[待用户提供原始出处]`，**禁止**用占位信息补全后冒充真实文献。

## 字段级交叉验证（多源比对）

对含 DOI 的文献执行三方比对：

| 比对对 | 检查内容 |
|---|---|
| DOI vs Crossref | DOI 可解析，返回的标题/作者/年份与所引一致 |
| 卷期页码 vs Crossref | 卷、期、页码与 Crossref 元数据一致，无误引页码 |
| 作者年份 vs 正文 | 正文 [作者, 年份] 占位与文献表一致；同名作者不混淆 |

警惕三个高频混淆：
- 同名作者不同人（用机构/ORCID 区分）；
- 同一工作的会议版 / 期刊版 / 预印本（引用正式发表版本并标注）；
- 同一标题多篇（用 DOI 唯一锁定）。

## 他引审计（区分"被引"与"真实认可"）

- 引用计数 ≠ 领域认可：高被引可能是自引、引用圈或方法惯性，不代表结论被验证。
- 判断某篇论文"被领域接受"时，检查**他引来源的多样性**：被多个独立团队、多个方向引用，才是可信影响力信号。
- 被引数注明统计来源与时间（Google Scholar / Scopus / Web of Science 口径差异大），不得混用。
- 反向审计：正文若声称"本研究填补了 X 空白"，必须确认 X 确实无人做过（前向追踪 + 全库检索），否则是夸大 claim。

## 输出物

每条文献记录最终形态：

```
[作者, 年份] 标题. 来源. DOI. 核心观点. 与本主题关系. 验证状态(已验证/待核实)
```
