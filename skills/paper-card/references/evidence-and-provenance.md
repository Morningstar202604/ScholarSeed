# evidence-and-provenance：证据与溯源原则

## 证据分级

| 级别 | 含义 | 卡片中的处理 |
|---|---|---|
| 原文证据 | 作者原文明确陈述（数字/结论/公式） | 引用原文并给定位（页码/图表/公式） |
| 结构证据 | 由方法/实验设计可推导的隐含信息 | 标注"由 X 推导"，不冒充原文 |
| 推断 | Agent 基于证据的推理 | 用"Agent 注："明确标注 |
| 外部证据 | 来自外部检索 | 必须给外部来源引用 |

## 作者陈述 vs Agent 分析分离

- 作者陈述：忠实呈现，可精确引用或明确标注 paraphrase，不替作者"补全"逻辑。
- Agent 分析：以独立段落呈现，前缀"Agent 注："，判断必须落到具体证据而非印象。
- 一条铁律：不能用"论文指出"包装 Agent 自己的判断，也不能用 Agent 的判断覆盖作者原文。

## 定位引用规则

- page-grounded：页码 + 结构定位（如 "p.5, Fig.2"），区分 PDF 页索引与印刷页标。
- structure-grounded：章节/图表/公式编号，不给页码。
- source-limited：不给页码，不推断未见证据。
