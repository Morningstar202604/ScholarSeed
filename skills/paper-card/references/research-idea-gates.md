# research-idea-gates：候选研究思路检查

写第 16 段"可检验的研究思路"前，逐条过这三道门：

## 门 1：新意（不是已有工作）
- [ ] 该思路是否已被领域内做过？（前向追踪 + 全库检索）
- [ ] 若有人做过，我的增量是什么？
- [ ] 检查不通过 → 去掉或改写增量方向，不写"填补空白"的空话。

## 门 2：可检验（能设计出判别实验）
- [ ] 能否给出一个能证伪它的检验方案？
- [ ] 需要什么数据？数据可获得吗？
- [ ] 无法设计检验 → 这不是研究思路，是空想，删除。

## 门 3：可传播（值得写成论文）
- [ ] 解决的是真问题（有人关心）还是玩具问题？
- [ ] 目标出口（期刊/会议）是否有此方向偏好？

## 输出格式
每条思路：

```
- 假设：<一句话>
- 检验方法：<判别实验设计>
- 需要数据：<数据来源与获取途径>
- 关联：<基于卡片第 06/09/12 段的哪部分>
```
标注"假设，非结论"。禁止把思路包装成"本文作者暗示的方向"——那是作者的主权。
