# card-schema：16 段证据卡片字段模板

## 卡片头部

```
# Paper Card: <题名>
- 作者: ... | 年份: ... | Venue: ...
- DOI: ... | 访问状态: 全文/摘要/元数据
- 定位模式: page-grounded / structure-grounded / source-limited
```

## 各段字段

### 01 文献定位
题名、作者（含 ORCID 若可得）、年份、venue、DOI、预印本版本、访问链接、访问日期。

### 02 研究问题
- 一句话研究问题（可证伪形式）
- 作者宣称的贡献（原文引用或标注 paraphrase）

### 03 背景脉络
- 领域位置（哪个子领域、承接谁的工作）
- 标注：这是作者叙述还是外部核验结果

### 04 痛点
- 作者指出的现状缺陷（区分：技术缺陷 / 证据缺陷 / 概念缺陷）

### 05 核心洞见
- 一句话：本文最核心的新认知

### 06 方法
- 组件清单、输入输出、前提假设、数据流
- 每个假设是否被作者检验

### 07 模块逻辑
- 每个模块/步骤 → 论证角色（为什么存在）
- 哪些模块可有可无（作者是否做了消融）

### 08 关键公式
- 公式 + 符号表 + 假设条件 + 与前后文的连接

### 09 实验-主张证据链
- 主图/主表编号 → 支撑主张 → 基线对比 → 缺口
- 每个实验是否有统计显著性、效应量、多次重复

### 10 结论边界
- 适用条件、数据集范围、不适用场景

### 11 作者自述局限
- 原文（引用或精确 paraphrase），不改写为 Agent 批判

### 12 批判性分析
- Agent 独立判断：证据是否充分支撑主张；过度声称；未报告项
- 用"Agent 注："前缀，与作者陈述分离

### 13 学到的知识
- 可迁移要点（方法/设计/写作层面）

### 14 知识连接
- 与领域其他工作、用户自身研究/项目的关系

### 15 外部核验
- 领域史、新颖性声明的外部检索结果；引用来源；未核验项标"无外部验证"

### 16 可检验的研究思路
- 每条：假设 + 检验方法 + 需要的数据；标注"假设，非结论"

## 特殊值
- 材料不足 → `Not assessable from supplied material`
- 论文不适用 → `Not applicable`
- 禁止用空格、占位符号糊弄；写不出就如实标注。
