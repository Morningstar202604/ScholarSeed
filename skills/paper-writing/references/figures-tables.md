# 图表制作规范（Figures & Tables）

图表是论文的"证据可视化层"。好的图表让审稿人 30 秒内理解核心结果；差的图表会掩盖好工作。

## 一、图（Figures）

### 1.1 基本规范

- **一图一主题**：一张图只回答一个问题，不要堆砌多面板无关内容。
- **坐标轴**：必须有轴标题 + 单位；刻度清晰；对数尺度要标注。
- **误差与统计**：有均值/方差就画误差线；组间比较标注显著性（\* p<0.05, \*\* p<0.01, \*\*\* p<0.001，并在 caption 说明检验方法）。
- **分辨率**：投稿图 ≥ 300 dpi；位图用 PNG/TIFF，矢量图优先 PDF/SVG。
- **色彩**：考虑色盲友好（红绿不用作唯一区分手段）；黑白打印仍可读。
- **字体**：图中文字大小与正文一致或略小，统一字体。
- **编号引用**：正文必须按出现顺序引用"图 1、图 2…"，每张图正文中都应有一段解释。

### 1.2 常见图类型选择

| 数据关系 | 推荐图 |
|----------|--------|
| 趋势（时间/epoch） | 折线图 |
| 分布 | 直方图 / 箱线图 / 小提琴图 |
| 构成占比 | 堆叠柱 / 饼图（慎用，柱状更严谨） |
| 两变量关系 | 散点图 + 拟合线 |
| 对比多组 | 分组柱状图 |
| 高维降维 | PCA / t-SNE / UMAP |
| 流程/架构 | 示意图（矢量绘制） |

### 1.3 常见错误

- 截断 Y 轴放大差异（误导）
- 3D 图、装饰性渐变、无意义配色
- 图例缺失或位置遮挡数据
- caption 不完整（不说明样本量、检验方法、缩写）

## 二、表（Tables）

- **三线表**：顶线、栏目线、底线，其余无线（期刊常规风格）。
- **表头自明**：含变量名、单位；缩写首次出现处脚注解释。
- **显著性标注**：统一用星号或上标字母，脚注说明。
- **数据与正文一致**：表中数字与正文/图严格对应，不可互相矛盾。
- **不宜用表的情形**：少量数据用文字即可；大量原始数据放附录。

## 三、图表与正文的关系

- **先后逻辑**：正文讲逻辑与结论 → 图/表给证据 → caption 讲清"怎么读这张图"。
- **Caption 模板**：编号 + 一句话结论 + 数据说明（样本量/条件/检验） + 缩写/图例说明。
- **禁止**：正文已写结论但无图表支撑；或图表存在但正文未解释。

## 四、AI 辅助图表守则

- AI 生成图表必须人工核对：数值、单位、坐标轴、显著性标注。
- 数据必须来自真实实验结果，AI 不得"补全"缺失数据点或美化显著性。
- 图片导出前检查：分辨率、字体、色彩模式（RGB）、尺寸符合目标期刊要求。
