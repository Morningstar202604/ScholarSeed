# plain-writing：朴素写作 25 条（去 AI 味的终极清单）

集成 docwriter plain-writing skill 的完整规则集。比 `ai-cleanup.md` 更系统：它给出**可逐条对照的正反例**。适用：论文正文、回复信、README、任何要"读一遍就懂"的文本。

## 一、词汇与语气

1. **用简单日常词**：平词能表达就不选 fancy 同义词；禁用 AI 高频词（delve / tapestry / landscape / robust / leverage / "深入探讨" / "赋能"）。
2. **不用行话**：能用人话就用人话；专业术语只在最精确处使用，读者可能不懂时给一句话定义。
3. **去掉空强调**：删掉不加信息只加力度的词（really / real / matters / pivotal / renowned / "值得注意"）。要么写事实，要么删句子。
4. **术语统一、收敛词汇**：同一概念全文一个词。例：别一段"上传文档"、下段"解析文件"。
5. **可以用缩写**：don't / it's 贴近口语，正常使用。
6. **不发明连字符形容词**：字典里查不到的复合词不用（避免"reveal-style colon"式自造）。
7. **保持朴素、描述性**：不用标语式/抓眼球的标题和措辞，标题就直说内容。

## 二、句子与段落

8. **写完整句**：每句有主谓；不用碎片句；不相干观点不用冒号/分号硬缝。
9. **流程按顺序讲**：用 First / Second / Third，每步独立成句。
10. **段首结论句 + 支撑**：先主题句点题，再给例子/事实支撑，用"例如 / 此外"连接。
11. **一句最多两个从句，示例最多连排两条**：三连从句和三连示例都是 AI 味。
12. **长解释句优先于短句**：像人面对面解释那样写（逗号 + 平实），不堆短句、不写抓眼球短句。
13. **精确无歧义、删冗余从句**：说清"谁做了什么、机制如何"；删"在叫停之前""从长远来看"这类空后缀。
14. **聊天场景给上下文**：为没有上下文的读者补一句背景再讲变化（论文写作本文件不适用，但回复信适用）。

## 三、标点与格式

15. **不用破折号 / 间隔点**：不用 em dash / en dash，包括数字范围（写 "10 to 20"）；不用 · 作分隔。
16. **普通散文中冒号不连接子句**：冒号只用于引出列表或作短标签（Summary: / Changes:）。
17. **用直角引号/直引号**：不用弯引号。
18. **格式朴素**：标题用句首大写；加粗不做装饰。
19. **列表克制**：列表限制在 3-4 项；论文正文极少量用列表与表格。

## 四、要避免的模式

20. **不给无生命物假动作**：不写"系统决定 / 日志成为可检索记录"，写"你可以搜索日志"。"论文指出"这类论文主语可以保留（学术惯例）。
21. **不用类比/比喻**：不用"像图书馆目录卡"解释，直接描述本体。
22. **不用"不仅是 X，更是 Y"式否定平行**：直接说它是什么。
23. **不堆反问句**：AI 写作爱连排两三个反问装深沉；直接陈述问题。
24. **不用模糊指示代词**：不滥用 This / That / These 开头（尤其段落首句）。
25. **不以"数要点"开场**：不写"两点提醒""三点注意"；直接讲第一点。

## 五、执行方式

- 对成稿逐条扫 25 条，每命中一处给出 Before → After；
- 全部规则只改表达，**不改事实、不删数据、不弱化结论**（与 `ai-cleanup.md` 铁律一致）；
- 与 `ai-cleanup.md` 的 AI 痕迹清单配合：ai-cleanup 抓"AI 味特征"，本文件给"朴素写法标准"。
