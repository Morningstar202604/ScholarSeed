# 质性研究严谨性对照（qualitative rigor）

> 用途：质性稿件（访谈/民族志/个案/扎根理论/现象学）的质量门禁——
> 定量的 p 值与样本量口径在此**整体失效**，替换为下列可信性标准。
> 与 discipline-matrix.md 的路由规则配合：质性稿跳过 check_stats/check_numbers，
> 用本表逐项人工核验。

## 一、抽样透明度

- [ ] 抽样策略写明（目的性抽样/理论抽样/最大差异抽样/便利抽样及理由）；
- [ ] 样本量给出并论证（饱和度证据：第几份访谈后不再出现新主题）；
- [ ] 招募渠道、纳入/退出标准、时间窗交代；
- [ ] 研究者与被试关系披露（师生/同事/利益关联）。

## 二、数据收集可审计

- [ ] 访谈提纲/观察协议附附录或声明可得；
- [ ] 录音转写方式逐字/要点注明；翻译稿说明回译程序；
- [ ] 收集时长总量（如"32 次访谈，平均 55 分钟"）；
- [ ] 现场笔记与背景记录的处理方式。

## 三、分析过程留痕

- [ ] 编码方法命名（主题分析 Braun & Clarke / 扎根理论三级编码 / 内容分析）；
- [ ] 编码过程可追溯：开放编码 → 类属 → 主题的演进示例至少一组；
- [ ] 多编码者信伪：第二编码者参与比例与分歧解决机制（或如实声明单编码者局限）；
- [ ] 引语标注规范：受访者编号 + 来源行，引语与编码主题对应。

## 四、可信性标准（Lincoln & Guba 四判准）

| 判准 | 对应做法 | 常见审稿质疑 |
|------|----------|--------------|
| 可信 Credibility | 三角验证（多来源/多方法/多研究者）、member checking | "结论只是研究者的解读？" |
| 可转移 Transferability | 厚描述（thick description）场景细节 | "换个场景还成立吗？" |
| 可靠 Dependability | 审计轨迹（编码簿/备忘录留存） | "换人分析结果一样吗？" |
| 可确认 Confirmability | 反思日志、数据与分析对得上 | "是不是把预设强加给数据？" |

## 五、研究者位置反思（reflexivity，文科/社科必查）

- 研究者的身份、立场、预设如何影响提问与解释——显式写出一段；
- 不假装"客观中立零介入"；介入如何管理要交代。

## 六、常见拒稿质疑点（预答辩清单）

1. "样本怎么选的？为什么是这些人？"→ 第一节逐项回答；
2. "怎么知道饱和了？"→ 给出饱和证据而非断言；
3. "引语是不是断章取义？"→ 引语带上下文与编号，负案例也呈现；
4. "理论框架是事后套的吗？"→ 说明框架进入分析的时点；
5. "AI 参与了转写/编码吗？"→ 按期刊政策披露，人工核验环节写明。

## 七、工具使用边界

- `verify_references`/`citation_verify`：仍适用于文献综述部分（注意图书类覆盖弱）；
- `proofread` 语言层检查可用；`check_stats`/`check_numbers` **不适用**；
- AI 痕迹画像按 discipline-matrix 降级为参考。
