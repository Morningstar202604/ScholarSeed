# 学位论文专项规范（Thesis & Dissertation）

学位论文与期刊论文在目标、篇幅、流程与评价维度上不同。本节覆盖从开题到定稿归档的学位论文特有流程，供"学位论文 / 学位章节"体裁使用。学校流程与格式以目标院校规定为准，本规范负责内容组织与写作质量，不替代学校流程。

## 一、学位论文全流程（时间线）

1. 开题论证（开题报告 + 开题答辩）
2. 中期检查（进度 + 初步结果）
3. 正文写作（多章节）
4. 查重（初稿自查 → 修改 → 终稿以学校系统为准）
5. 送审 / 盲审（外审意见回复）
6. 答辩（陈述 + 问答）
7. 定稿归档（终稿 + 上传学位库）

## 二、章节结构（与期刊 IMRaD 的差异）

典型学位论文结构：

- 第 1 章 绪论：研究背景与意义、国内外研究现状（综述）、研究内容/方法/技术路线、组织结构
- 第 2 章 相关理论基础：领域核心概念、方法基础
- 第 3-5 章 核心研究内容：按"问题 → 方法 → 实验"组织，每章一个完整研究闭环
- 第 6 章 总结与展望：工作总结、创新点、不足与展望
- 参考文献 + 附录（问卷 / 数据 / 代码）

差异要点：

- 篇幅差异大（本科约 1-3 万字、硕士约 3-8 万字、博士约 8-20 万字），深度与创新性要求逐级递增。
- 每章自成闭环（章内引言 + 方法 + 结果 + 小结），而非全篇单一 IMRaD。
- 绪论中的文献综述是独立章节，要求系统、全面、有时序脉络，并落到研究缺口。
- 创新点需显式提炼，通常同时在摘要、绪论、结论三处出现，且口径一致。

## 三、开题报告要素

- 选题背景与意义（为什么做）
- 国内外研究现状与缺口（现状 + 缺口）
- 研究内容、方法、技术路线（做什么、怎么做）
- 预期成果与创新点
- 进度安排与可行性

## 四、查重与原创性（合规口径）

- 查重是学校检测流程，最终以学校指定系统为准，本插件不做查重承诺、不替代检测。
- 合规做法：引用必须标注；直接引用加引号与出处；改写必须以重写表达实现，而非替换同义词。
- 禁止：购买降重服务、机械替换同义词、整段翻译国外文献冒充原创、打乱句子顺序应付查重。
- 自查方式：定位重复段落 → 重写表达 → 核对原意是否保留、出处是否仍在；对自己既往稿件的重用，先用 `check_self_plagiarism(markdown=全文, corpus_dir=历史稿目录)` 做 n-gram 重叠机检（合理复用也会命中，需人工判断改写或规范引用）。

## 五、盲审 / 外审应对

- 盲审看重：选题价值、创新性、方法规范、工作量、格式规范、文献质量。
- 送审前对照：图表编号连续、参考文献格式统一、无错别字、公式编号、目录已更新、页眉页脚正确。
- 盲审意见回复：逐条回应，能改的改并说明修改位置，不同意的给出依据，态度诚恳。

## 六、答辩材料

- 陈述 PPT：10-15 分钟，讲清"为什么做 → 怎么做 → 结果如何 → 创新点"。
- 陈述要点：研究问题一句话讲清；方法与结果用图表讲清；创新点不夸大、有证据。
- 常见提问：创新点是否成立、方法局限、与已有工作的区别、工作量分配、后续工作。

## 七、学位论文与期刊论文的转换

- 学位论文中的一章（或主要结果）可拆出投期刊/会议；先确认目标院校与目标期刊对"先发期刊后入学位论文 / 重复发表"的政策，合规后再操作。
- 期刊论文要求更聚焦：一个贡献讲透，压缩背景综述，将多章内容收敛为单章 IMRaD。
