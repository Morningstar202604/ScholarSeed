# statistical-analysis：统计方法与报告红线（集成 K-Dense statistical-analysis + nature-statistics）

论文中涉及数据统计分析的选型、假设检验与报告规范。吸收 K-Dense 统计技能（检验选择、效应量、power、Bayesian）与 nature 系统计审查红线。

## 1. 检验选择速查

| 场景 | 检验 |
|---|---|
| 两组连续变量比较 | t 检验（独立/配对） |
| 三组及以上组间比较 | ANOVA + 事后检验（Tukey/Bonferroni） |
| 分类变量关联 | 卡方检验 |
| 两连续变量关系 | Pearson/Spearman 相关、线性回归 |
| 多因素影响 | 回归（线性/逻辑） |
| 小样本/非正态 | 非参数替代（Mann-Whitney / Kruskal-Wallis / Wilcoxon） |

## 2. 假设检验前置检查（必做并报告）

- **正态性**：Shapiro-Wilk + Q-Q 图 + 直方图；
- **方差齐性**：Levene 检验 + 箱线图；
- **线性性**：散点图 + 残差图（回归）；
- **回归诊断**：残差 4 联图 + Breusch-Pagan + Durbin-Watson + VIF（共线性）。

**先检查假设再解释结果，并把检查情况写进论文**——审稿人会找这个。假设不满足时改用补救检验（见上表），同时报告"原计划 + 补救方案 + 两者结果"。

## 3. 效应量 + 置信区间（p 值的必要补充）

- p 值只说明"效应是否存在"，效应量说明"是否值得关心"——**两者必须一起报**。
- 常用效应量：Cohen's d（t 检验）、η² / partial η²（ANOVA）、Cramer's V（卡方）、r（相关）。
- 效应量必须带置信区间；只报 p < 0.05 不报效应量 = 信息残缺。

## 4. Power 分析

- **事前 Power**（研究设计期）：给定 α、效应量、power(通常 0.8)，估算所需样本量；样本量不足如实声明。
- **事后敏感性分析**：给定样本量与 α，报告能检测到的最小效应量。
- 不报告 power 的"无显著差异"结论不可靠——可能只是样本不够。

## 5. Bayesian 备选（可选）

- 样本极小、先验可得时可用：指定先验 → 计算 Bayes Factor / 可信区间 → 检查收敛（R-hat < 1.01）。
- 报告：先验设定理由、BF 数值、与频率学派结果的一致性。

## 6. 报告规范（APA 风格模板）

```
t(自由度) = 值, p = 值, d = 值, 95% CI [下限, 上限]
F(组间df, 组内df) = 值, p = 值, η²p = 值
χ²(df) = 值, p = 值, V = 值
```

每次检验报告：描述统计 + 精确检验统计量 + 效应量（带 CI）+ 已做的假设检查。

## 7. 统计红线（nature 系审稿硬性要求）

- **样本量（n）**：每张图/每个结论必须注明 n 与重复次数；n 缺失 = 不可评估。
- **独立重复 vs 技术重复**：必须区分生物学/独立样本重复与技术重复；把技术重复当独立样本是审稿硬伤。
- **多重比较**：多次检验必须校正（Bonferroni / FDR），并声明校正方法。
- **p 值陷阱**：不把 p<0.05 当圣杯；显著性的边界情况（0.04-0.06）如实报告原始 p 值，不做无依据取舍。
- **异常值**：剔除异常值必须说明标准、数量与剔除前后的结果。
- **不报道负结果**：检验不显著 ≠ 无效应，可能 power 不足；如实报告并讨论。
- **不能把相关当因果、把不显著当等价**：这是统计表述的红线，禁越。

## 8. 写作时的落地

- 方法章节写明：检验类型、假设检查、多重比较校正、软件与版本、显著性阈值；
- 结果章节每处统计报告走第 6 节模板；
- 讨论章节不夸大统计结论，不把探索性结果当确认性结论。
