# 论文结构模板

通用章节骨架，按体裁裁剪。

## 综述型论文

1. 标题（含研究对象与视角）
2. 摘要（200-300 字：背景-问题-方法-结论）
3. 关键词（3-5 个）
4. 引言 Introduction
   - 背景与研究意义
   - 现状概述与已有工作
   - 已有工作的局限/缺口
   - 本文目的与贡献
5. 综述主体（按主题/时间线/流派组织）
   - 领域核心概念与分类
   - 代表方法与工作（每个：核心思想-优劣-适用范围）
   - 对比分析（可用表格）
6. 关键问题与挑战
7. 未来方向
8. 结论
9. 参考文献

## 实证研究型论文（IMRaD）

1. 标题
2. 摘要（结构化：目的/方法/结果/结论）
3. 关键词
4. 引言（问题提出 + 文献 + 假设）
5. 方法 Methods（样本/设计/指标/分析流程）
6. 结果 Results（数据 + 图表）
7. 讨论 Discussion（结果解读-与文献对照-局限）
8. 结论 Conclusion
9. 参考文献

## 技术报告/博客长文

1. 标题（痛点/价值导向）
2. 摘要框（3-5 行讲清：做了什么、解决什么）
3. 背景与动机
4. 方案设计（含图）
5. 关键实现细节（代码/配置）
6. 效果与数据
7. 局限与后续
8. 参考链接

## 篇幅分配参考

| 章节 | 占比 |
|------|------|
| 引言 | 10-15% |
| 综述主体/方法 | 40-50% |
| 讨论/结果 | 20-25% |
| 结论 | 5-8% |
| 参考文献 | 不计入正文 |

## 写作执行要点（实证方法论）

### 摘要（150-300 词，五要素）
背景 → 研究缺口 → 本文方法 → 关键结果 → 结论。独立可读：读者只看摘要也能还原研究全貌，不引用图表编号与文献编号。

### 引言（漏斗结构）
从宽到窄逐层收口：领域大背景 → 已有研究现状 → 具体缺口/未解问题 → 本文方案与贡献列表。第一段就要让读者明白"为什么值得读"；贡献用编号列表给出，每条可被正文章节对应验证。

### 方法（可复现优先）
数据来源、实验设置、超参数、评估指标、统计方法逐项写清；读者应能据此复现。无法公开的部分明确说明。

### 结果 vs 讨论（职责分离）
结果只陈述事实与数据，不解释；解释与对照放讨论。图表自明（标题含完整信息，正文可不读也能懂图）。

### 各节修辞动作（Rhetorical moves）
- 引言：确立领域 → 指出缺口 → 提出填补方案 → 列出贡献 → 预告组织结构。
- 讨论：复述主要发现 → 机制解释 → 与已有文献对照（支持/分歧）→ 承认局限 → 结论与展望。
- 相关工作：先分类再逐类评述，明确"已有工作做了什么 / 没做什么"，突出本文差异。

### 压缩操作（成稿后）
信息密度优先，对每节执行：删重复、并小节、缩表格、去套话；长文建议压缩 30-50%，保留全部关键数据与结论。
