# 选题与构思（Topic Selection & Ideation）

论文起点决定终点。本节规范"想法 → 可写研究问题 → 值得做的选题"的完整路径。

## 一、选题来源（6 类）

| 来源 | 方法 | 举例 |
|------|------|------|
| 文献缺口 | 读综述 Conclusion/Future Work；精读文献的 Limitation | 综述末节常列 3-5 个未解决问题 |
| 交叉领域 | 把 A 领域方法迁移到 B 领域问题 | NLP 技术用于医学文本 |
| 复现与延伸 | 复现他人结果 → 换数据/换环境/加约束 | 复现后加消融或新场景 |
| 现实问题 | 行业痛点、公开数据集大赛、政策需求 | Kaggle 赛题、政府报告 |
| 合作与讨论 | 导师/同事/学术会议交流 | 会议 poster 墙 |
| 旧题新做 | 经典问题的规模/方法/评价维度更新 | 大模型时代的经典任务 |

## 二、研究问题四要素（PICOT 变体）

一个可写的研究问题必须能回答这 4 个要素（实证研究）：

- **P（对象）**：研究谁/什么（人群、系统、材料、数据集）
- **I（干预/输入）**：施加什么（方法、模型、处理、自变量）
- **O（结果）**：测量什么（指标、效应、输出变量）
- **T（范围/时间）**：场景、时间窗、边界条件

反例："人工智能如何影响教育？"→ 过宽、不可证伪。
正例："在小学英语课堂场景（P）引入大语言模型辅导（I）对口语流利度得分（O）的影响，12 周实验（T）"。

理论/方法类论文改为回答：**问题 → 现有方法不足 → 我的新方法 → 为什么更好 → 证据**。

## 三、选题评估五维打分（每维 1-5 分，总分低于 15 建议换题）

1. **新颖性**：与已有工作是否有可明确陈述的差异（检索 3-5 年文献确认无重复）。
2. **重要性**：解决的是真实问题还是人造问题？目标读者是否在意？
3. **可行性**：数据/算力/设备/时间是否可得？48 小时内能否产出小规模验证（pilot）？
4. **可证伪性**：是否存在一种观察结果能证明假设错误？
5. **可发表性**：是否能对应到至少 1 个明确目标期刊/会议的主题范围？

## 四、定位贡献（gap 分析）

写作前用一句话模板锁定贡献，全文围绕它：

> "已有工作解决了 __（旧问题/旧方法/旧场景）__，但 __（缺口）__；本文提出 __（新方案）__，通过 __（证据）__ 证明 __（改进点）__。"

## 五、选题避坑清单

- [ ] 题目过宽（能拆成 3 篇以上）或过窄（不足以成文）
- [ ] 无真实 gap（只是换个数据集重复已有结论）
- [ ] 不可证伪 / 结果无法测量
- [ ] 依赖不可获得的数据或设备（写前未确认）
- [ ] 与已发表工作重复（检索不充分）
- [ ] 选题热门但 3 个月内已被做滥（预印本抽查）

## 铁律

- 选题阶段必须产出《选题论证》：研究问题四要素 + 五维评分 + gap 模板 + 初步检索证据，缺一不可。
- 禁止仅凭直觉选"看起来热门"的题；每个维度都要有可核验依据。

## 思维环节：先分类再选题（集成 superpowers brainstorming）

动笔选题前，先把任务分成三档并明说，避免在错误方向上写完大纲：

| 路径 | 选题场景 | 流程 |
|---|---|---|
| Spike（探针） | "这个方向能不能做"——只要可行性答案 | 2-3 句探针计划 → 确认 → 低成本验证 → 结论是建议非成品 |
| Bounded（有界） | 研究问题已定，在既定框架内收窄 | 问清关键问题 → 对话内简短设计 → **停下等确认** → 再写 |
| Architectural（架构） | 新选题/新综述框架 | 逐问澄清 → 2-3 个候选方案带取舍 → 分段设计逐段确认 → 再动笔 |

- 一次只问一个真正影响方向的问题，优先选择题；
- 任何选题无论多"简单"，动笔前必须让用户对《选题论证》点头——简单只是设计短，不是没设计；
- 不确定时走更重的路径；写作中发现复杂度升级，立即停下说明并升级，禁止中途降级。
- 完整思维协议见 `thinking-protocol.md`。
