# 审稿返修与回复信（Review Response & Revision）

收到审稿意见 ≠ 结束，返修质量决定成败。逐条回复的严谨度与修改的诚意，比写作技巧更影响录用。

## 一、收到意见后的处理流程

1. **通读全篇**：先读主编决定信（Accept / Minor / Major / Reject-resubmit），再读所有审稿人意见。
2. **分类归档**：把每条意见编号，分类为：
   - 实验/方法类（需补实验、改方法）
   - 写作/表达类（改措辞、补解释）
   - 文献类（补引用、纠错）
   - 质疑类（挑战结论/统计）
   - 偏好类（可接受可不接受）
3. **评估接受度**：能改的改；有数据支撑的合理拒绝；每类都要给明确答复。
4. **制定修改计划**：按投入产出排序，先补关键实验，再改文字。

## 二、Response Letter 结构（逐条回复）

对每条意见的标准三段式：

1. **复述意见**（引用原文或编号）："Reviewer 1, Comment 3: …" 确保审稿人不用翻原文。
2. **致谢/判断**："We thank the reviewer for this valuable comment."
3. **回应 + 修改位置**：
   - 已改：说明改了什么，指出"见 Manuscript Page X, Line Y"；
   - 部分接受：说明做了什么程度；
   - 不接受：给出数据/逻辑依据，语气礼貌（"We respectfully disagree because…"）。

## 三、回复要点与禁忌

- **逐条回应，绝不漏项**：漏一条 = 给审稿人留把柄。
- **语气**：始终礼貌专业，对尖锐意见也不争辩、不反击。
- **区分"改了"与"回复了"**：光解释不改稿会被拒；光改稿不写清位置审稿人看不出。
- **补实验要真实**：补做实验必须真实执行并如实报告，禁止"假装补了"。
- **高亮修改**：修改稿中通常要求标注修改处（高亮/红字/track changes）。
- **回复信长度**：可长，但不啰嗦；能用表格对比"原句→修改后"更清晰。

## 四、Major Revision 策略

- 若多个审稿人重复提同一问题 → 优先解决（说明是普遍关切）。
- 对"补大规模实验"类要求：能补则补；无法补（资源/时间）时，明确说明限制并提出替代证据，可同时说明该限制对未来工作的意义。
- 修改后重投同样要写 cover letter 说明大改概况。

## 五、拒稿后的选择

- **Major 转 Minor 被拒**：理性判断——若意见分歧严重可申诉（需强理由），否则改投他刊。
- **改投**：按新目标期刊要求重新排版、重写 cover letter、必要时按新期刊范围调整内容。
- **申诉**：仅当存在事实性误解/程序错误时使用，礼貌陈述，一次机会。

## 铁律

- 逐条意见必须有对应回应，禁止选择性回复。
- 回复信中的一切"已修改/已补充"必须真实对应修改稿，禁止空承诺。

## 逐点返修信规范（集成 nature-response）

给审稿人的返修信按"逐点对应"组织，核心是让审稿人 10 秒定位"我的意见 → 你怎么改的 → 改在哪"：

1. **逐点对应**：每条审稿意见单独一段，编号与审稿意见一一对应，禁止合并或选择性跳过。
2. **三段结构**：每条回复 = 复述意见（确认理解）→ 说明修改（具体动作）→ 定位（正文/图表/页码）。复述不改变审稿人原意。
3. **修改证据**："已修改"必须可定位（文件、章节、行号），并附修改前后摘录；无法修改的给出理由与替代方案，不空承诺。
4. **互盲隔离**：多审稿人时逐位回复，意见与回复严格对应各自审稿人，不串号、不混淆。
5. **cover letter 附带**：首投/返修时的投稿信同步起草（见 `cover-letter.md`），说明改动概要。
6. **语气纪律**：感谢但不谄媚；争议点摆证据讲理，不正面顶撞；所有分歧点给出依据让编辑裁决。

交付物：《返修信》+《修改对照表》（意见 / 修改动作 / 定位 / 状态 四列）。
