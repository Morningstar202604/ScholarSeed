# 发布平台规则速查

## 学术期刊投稿

- 出口：期刊官网投稿系统（如 Elsevier Editorial Manager、ScholarOne、知网采编系统）
- 格式：一般要求 LaTeX 或 Word 模板；投稿系统内逐字段填写
- 必备元信息：标题、作者、单位、摘要、关键词、利益冲突、基金
- 必须由作者确认：作者署名与顺序、通讯作者、查重报告、版权协议
- 伦理红线：**一稿多投禁止**；同一稿件不得同时投多个期刊
- 实际提交：需要账号登录 + 人工确认，插件输出投稿指引与成稿

## arXiv 预印本

- 出口：arxiv.org
- 格式：LaTeX 为主，需先注册账号、配置作者身份
- 发布前注意：可能影响后续期刊对"首次发表"的认定，需用户自行确认期刊政策

## 微信公众号

- 出口：微信公众平台（mp.weixin.qq.com），订阅号/服务号
- 格式：富文本；推荐分段短、配小标题、加导语与摘要框
- 限制：正文建议 ≤2000 字（长文可拆系列）；需原创声明；图片需有版权或授权
- 实际发布：需要登录公众号后台，插件输出排版稿

## 知乎专栏 / 文章

- 出口：zhihu.com
- 格式：Markdown 友好，可直接粘贴
- 适合：深度技术文、综述科普；可添加引用链接与目录
- 限制：无原创强制，但标注来源更合规

## 技术博客 / 自建站点

- 出口：掘金、CSDN、博客园、Hugo/Hexo 自建站、Medium、DEV 等
- 格式：Markdown 全量保留（代码块、表格、目录）
- 注意：各站有专属 Markdown 方言，发布前需做方言适配（如掘金图片外链、CSDN 标签）

## 通用规则

- 所有平台：先确认是否要求原创首发、是否支持转载标注、是否有敏感词审核。
- 发布状态必须真实：已提交/已发布/待用户操作，三类状态不可混用。
