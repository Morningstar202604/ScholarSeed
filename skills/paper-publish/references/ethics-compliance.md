# 学术伦理与合规（Ethics & Compliance）

学术不端是论文生涯的"一票否决项"。以下红线与流程在投稿/发表前必须逐项确认。

## 一、作者署名（ICMJE 四条标准）

通讯/署名作者必须**同时满足**以下 4 条，否则不具署名资格：

1. 对研究构思/设计、数据获取或分析作出实质贡献；
2. 起草或实质性修改稿件；
3. 最终版本审定；
4. 同意对研究整体负责。

不符合者只能列入致谢或担任"作者贡献"配角，禁止"赠予作者"（gift authorship）。

## 二、利益冲突

- 声明所有可能被感知的利益冲突：资助来源、任职、专利、咨询、亲属关系。
- 投稿系统 + 稿件内都要声明；无冲突也要写"作者声明无利益冲突"。

## 三、伦理审批（涉人/动物必查）

| 情形 | 要求 |
|------|------|
| 人体实验/临床数据 | IRB/伦理委员会批准号，受试者知情同意 |
| 动物实验 | 动物伦理审批号 |
| 使用他人数据/二次数据 | 遵守数据使用许可，注明来源 |
| 人源样本 | 匿名化 + 合规授权 |

- 稿件 Methods 或声明区写清审批机构与编号；缺失审批号是常见拒稿原因。

## 四、学术不端红线清单（逐项确认）

- [ ] **伪造**：编造数据、结果、实验记录（绝对禁止）
- [ ] **篡改**：选择性报告、删减不利数据、美化显著性（绝对禁止）
- [ ] **抄袭/洗稿**：未授权引用他人文字/思想；AI 痕迹兜底
- [ ] **幽灵/过度引用**：引用未读文献、为凑数引用
- [ ] **一稿多投**：同一稿件同时投多刊
- [ ] **重复发表**：无实质新增的重复出版
- [ ] **AI 使用未披露**：若期刊要求声明 AI 工具使用（写作/图表），须按政策披露
- [ ] **作者署名不当**：赠予/遗漏作者
- [ ] **数据不可用**：期刊要求数据可用性声明，数据应可复现

## 五、查重与自查

- 投稿前用查重工具（期刊官方推荐或 iThenticate 等）自查，重复率过高须改写。
- 自查重点：引言相关文献综述段落（易与原文重叠）、讨论复述。

## 铁律

- 伦理声明宁可多写不可漏写；不确定的合规项必须先向期刊编辑部确认，禁止想当然。
- 任何"AI 代写全文、代填审批、代签名"类操作一律禁止；AI 只辅助起草，责任与真实性由作者承担。
