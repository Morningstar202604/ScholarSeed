# 发表后传播与影响力（Post-Publication Dissemination）

发表 ≠ 终点。没有传播的论文等于"数字孤儿"。发表后的传播决定引用量、合作机会与学术声誉。

## 一、录用后的收尾事项

- **校样（Proofs）**：期刊发校样后尽快核对——数据、作者名、单位、图表编号、参考文献；改动仅限排版错误，不新增内容。
- **开放获取决策**：
  - Gold OA：支付 APC，立即免费公开，符合基金开放要求；
  - Green OA：在期刊允许的 embargo 后在机构库/预印本开放；
  - 核对基金（如中国国家自然科学基金）的开放获取强制要求。
- **版权**：确认出版协议保留的权利（自归档权、图表复用权）。

## 二、传播渠道（按投入产出排序）

| 渠道 | 形式 | 效果 |
|------|------|------|
| 学术社交网络 | ResearchGate / Academia.edu / LinkedIn 发布链接 | 学者圈内曝光，引用增长 |
| 预印本同步 | 若期刊允许，同步 arXiv/SSRN 更新版 | 即时可达，确立优先权 |
| 个人主页/机构页 | 附 PDF 与摘要 | 长期稳定入口 |
| 邮件列表 | 向相关研究组/讨论组发简明介绍 | 精准触达同行 |
| 学术会议 | 引用论文并作报告/poster | 面对面建立合作 |
| 科普传播 | 博客/知乎/公众号/短视频解读 | 大众影响力，基金和社会声誉 |
| 媒体互动 | 面向记者提供可读摘要 | 顶级成果可获主流报道 |

## 三、传播内容三要素（Any 渠道通用）

1. **一句话版本**：用一句话讲清"发现了什么、为什么重要"。
2. **可视化**：核心结果图 + 简要图表解释，比文字有效。
3. **开放链接**：DOI / 预印本链接 / 代码仓库 / 数据可用性链接。

## 四、引用与影响力追踪

- **Google Scholar Profile**：维护个人档案，追踪引用、h 指数。
- **Altmetric**：看社交媒体与新闻关注度。
- **定期复盘**：发表后 3/6/12 个月看引用增长，识别"该结果被谁引用"→ 发现潜在合作者或延伸方向。
- **代码与数据公开**：GitHub 仓库 + 数据可用性声明，显著提升复现与引用。

## 五、发表后可能的风险应对

- **被质疑**：有人提出复现问题 → 礼貌回应，提供数据/代码；确有问题则坦诚更正或撤稿。
- **勘误/撤稿**：发现错误按期刊流程发勘误（erratum）；严重问题（数据问题）主动撤稿，避免声誉损失扩大。
- **署名/单位争议**：通过期刊与机构沟通处理，不私下冲突。

## 铁律

- 传播内容必须忠于论文结论，禁止标题党式夸大。
- 公开代码/数据须符合伦理与版权要求（已获授权、不含敏感信息）。
