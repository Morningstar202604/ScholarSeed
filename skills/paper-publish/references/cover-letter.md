# 投稿信与投稿准备（Cover Letter & Submission Prep）

Cover letter 是编辑对稿件的第一印象。编辑每天处理几十封投稿，一封清晰有力的投稿信决定稿件是否进入送审。

## 一、Cover Letter 结构（5 段式）

1. **称呼**：写给主编（Editor-in-Chief），用投稿系统显示的姓名。
2. **第一段（30 秒抓住编辑）**：一句话说明稿件主题 + 研究问题 + 核心发现/贡献。
3. **第二段（为何值得发表）**：新颖性 + 重要性 + 与期刊 Aim & Scope 的契合（引用期刊近刊相关论文）。
4. **第三段（声明）**：原创性、未一稿多投、无利益冲突、（如需要）伦理审批号、数据可用性。
5. **结尾**：推荐审稿人（可选）、通讯作者联系方式、感谢审阅。

## 二、写作要点

- **长度**：300-500 词，一页内。
- **语气**：自信、简洁、不夸张（禁 "groundbreaking/revolutionary" 类空话，除非有实证）。
- **契合证明**：明确写出"本文契合贵刊 XX 方向，近期发表的 [具体论文] 相关"，让编辑感到你做过功课。
- **推荐审稿人**：3-5 位，说明理由（领域匹配、避免利益冲突），附机构邮箱。避免推荐近期合作者/同实验室。
- **禁忌**：不请求"快速处理"；不贬低竞争对手；不夸大成果。

## 三、投稿前材料核对清单（Checklist）

- [ ] 稿件格式符合《作者指南》（字数/图表数/结构/参考文献格式）
- [ ] 标题页：题目、作者、单位、通讯作者信息、字数统计
- [ ] 摘要符合目标期刊要求（结构化/非结构化、字数上限）
- [ ] 关键词（3-6 个，符合期刊惯例）
- [ ] 图表文件：分辨率、命名、编号、单独上传（如要求）
- [ ] Supplementary Material（补充材料，如需要）
- [ ] 作者贡献声明、利益冲突声明（模板按期刊）
- [ ] 伦理审批证明/知情同意（涉及人体/动物时）
- [ ] 数据可用性声明
- [ ] Cover Letter
- [ ] 所有参考文献完整且可访问（核对 DOI）
- [ ] 已通过自检（查重率、AI 使用披露按期刊政策）

## 四、投稿系统操作要点

- 首次投稿前注册 ORCID 并填进系统。
- 逐字段核对：作者顺序与邮箱（录用后修改作者极麻烦）。
- 保留投稿确认邮件与稿件编号；记录投稿日期。
- 系统提交后 24-48 小时内核对"With Editor / 状态"变化，异常时礼貌邮件询问。

## 铁律

- Cover letter 中每一条事实性声明（原创、无重叠发表、伦理合规）必须真实，可被核查。
- AI 撰写投稿信后必须人工复核全部声明项，禁止让 AI 代填伦理/授权类承诺。
